# POZZ frontend

Next.js PWA on Vercel. Product UI copy is Polish (preserve). Agent chat and new identifiers stay English.

```bash
npm install
npm run dev
npm run lint && npm test && npm run build
```

Env: `frontend/.env.example`. API pulse: `GET /api/health`. Voice lamp: `GET /api/voice/config`. Names: `docs/technical/configuration.md`.
